🎯 DEPLOY IN 3 STEPS:

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Test Locally (Optional but Recommended)                         │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   cd frontend                                                            │
│   ./verify-deployment.sh                                                 │
│                                                                          │
│   This will build and serve on http://localhost:5000                    │
│   Test login and make sure everything works!                            │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Deploy to Vercel                                                │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   OPTION A - Via Dashboard (Easiest):                                   │
│   ────────────────────────────────                                      │
│   1. Go to https://vercel.com/new                                       │
│   2. Import your GitHub repository                                      │
│   3. Configure:                                                          │
│      - Framework: Create React App                                      │
│      - Root Directory: frontend                                         │
│      - Build Command: npm run build                                     │
│      - Output Directory: build                                          │
│                                                                          │
│   4. Add Environment Variable:                                          │
│      Name:  REACT_APP_API_URL                                           │
│      Value: https://customermanagement-production.up.railway.app        │
│                                                                          │
│   5. Click "Deploy"                                                     │
│                                                                          │
│   ────────────────────────────────────────────────────────────          │
│   OPTION B - Via CLI (Fastest):                                         │
│   ────────────────────────────────                                      │
│   npm install -g vercel                                                  │
│   cd frontend                                                            │
│   vercel login                                                           │
│   vercel --prod                                                          │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Update Backend CORS (CRITICAL!)                                 │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   After deployment, Vercel gives you a URL like:                        │
│   https://your-app-name.vercel.app                                      │
│                                                                          │
│   1. Copy your Vercel URL                                               │
│   2. Go to: https://railway.app/dashboard                               │
│   3. Select your backend service                                        │
│   4. Go to Variables tab                                                │
│   5. Add/Update CORS_ORIGINS:                                           │
│                                                                          │
│      CORS_ORIGINS=https://YOUR-ACTUAL-URL.vercel.app,                   │
│                   https://YOUR-ACTUAL-URL-*.vercel.app,                 │
│                   http://localhost:3000                                  │
│                                                                          │
│   6. Railway will auto-redeploy (takes ~1 minute)                       │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ VERIFY DEPLOYMENT:

  Run automated tests:
  $ node test-deployment.js https://your-app.vercel.app

  Or manually check:
  1. Visit your Vercel URL
  2. Open DevTools (F12)
  3. Try logging in
  4. Check Console tab - should be no CORS errors
  5. Check Network tab - API calls should succeed
